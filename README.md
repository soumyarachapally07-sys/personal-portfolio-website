**Personal Portfolio Website**
**Project Title:**
Personal Portfolio Website

**Project Description**

This project is a responsive personal portfolio website that showcases my profile, skills, projects, and contact information.

**Technologies Used**

- HTML5
- CSS3
- JavaScript

**Features**

- About Me section
- Skills section
- Projects section
- Contact section
- Responsive design for different screen sizes
- Simple and user-friendly interface

**Setup Instructions**

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the "index.html" file in a web browser.
4. The personal portfolio website will be displayed.

**Project Files****
- "index.html" – Contains the structure of the website.
- "style.css" – Contains the styling and responsive design.
- "script.js" – Contains JavaScript functionality.
- README.md – Contains information about the project.
